AI Agent Governance Auditor | Personal Project, 2026
github.com/SomeRandomIntrovert/AI-governance-auditor
Most enterprises now run AI agents in low-code tools like n8n with little way to verify that risky actions are gated behind human approval. Built a Python/FastAPI auditing tool that scores workflows on approval gating (human oversight), error handling, audit trail (record-keeping), and credential exposure using forward-reachability graph verification, run as an automated n8n → FastAPI → Google Sheets → Looker Studio pipeline. Scoring dimensions map to the human oversight, logging, and robustness and security control themes in NIST AI RMF, ISO/IEC 42001, and the EU AI Act.
Result: audited 68 real public n8n workflows: only 2.94% were verifiably gated behind human approval, 55.88% ran fully autonomously with no approval gate, 0% had structured error handling, and 7.35% had any audit-trail logging.
